Осталась реализация тех же методов, что и в ветке json и добавился метод для изменения книги.

Формат хранения данных был заменен с json на БД Redis, подгруженную через docker.

Есть Makefile для удобного взаимодействия с приложением.

Для запуска приложения следует написать следующий ряд команд:
1) make docker-up -> запускаете контейнер
2) make app-start -> перемещаетесь в интерактивную командную оболочку (shell) внутри запущенного контейнера
3) ./lib -> запускаете саму программу

Для выхода сначала выберите в библиотеке 6 пункт или нажмите Ctrl+C, а затем напишите exit.
Docker контейнер можно удалить написав make docker-down
